# yandexmusic-mod
Мод на кастомизацию внешнего вида, яндекс музыки


- Как установить?
- 1. Нужно иметь на компьютере установленную оригинальную версию яндекс музыки
  2. Скачать с гитхаба YaMod-Setup
  3. Запустить эту ересь
  4. Запускать Яндекс мод с рабочего стола
 

Она не изменяет файлы обычной оригинальной яндекс музыки, если вам надоел мод, можете запустить обычную версию яндекс музыки как
