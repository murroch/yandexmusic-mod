## Что внутри

| | Возможность |
| :---: | --- |
| 🌌 | **Живой фон.** Видео на фоне «Моей волны» с возможностью отключить движение. |
| 🎵 | **Минималистичный плеер.** Название трека и управление воспроизведением в центре экрана. |
| 🎤 | **Синхронный текст.** Текущая и следующая строки песни, если для трека доступен синхронный текст. |
| ✨ | **Только караоке.** Режим с фоном и текстом без плеера и навигации. |
| 🧭 | **Быстрая навигация.** Переходы к поиску, «Моей волне» и коллекции. |
| ⚙️ | **Настройки под рукой.** Переключатели караоке и анимации с сохранением выбранных значений. |

Тема работает на странице **«Моя волна»**. При переходе в другие разделы отображается обычный интерфейс приложения.

## Установка

1. Установи оригинальное настольное приложение **Яндекс Музыка для Windows**.
2. Полностью закрой Яндекс Музыку, в том числе через значок в системном трее.
3. Скачай **[YaMod-Setup.exe](https://github.com/murroch/yandexmusic-mod/raw/refs/heads/main/YaMod-Setup.exe)**.
4. Запусти установщик и выполни установку.
5. Открывай мод через ярлык **Яндекс мод** на рабочем столе.

> **Хочешь вернуться к привычному виду?** Полностью закрой приложение и запусти Яндекс Музыку через её обычный ярлык. Скрипт мода применяет оформление во время запуска, не переписывая файлы установленной Яндекс Музыки.

## Настройки

Открой **«Мою волну»** и нажми на значок настроек в правом нижнем углу.

| Настройка | Что делает |
| --- | --- |
| **Только караоке** | Скрывает плеер, заголовок и навигацию, оставляя фон и строки песни. |
| **Движение фона** | Включает или выключает фоновое видео. При отключении остаётся статичное изображение. |
| **Обычный вид** | Отключает оформление в текущем сеансе. Повторное нажатие на значок настроек возвращает тему. |

**`Esc`** закрывает панель настроек. Если панель уже закрыта — выходит из режима «Только караоке».

Анимация автоматически приостанавливается, когда окно приложения скрыто. Если в системе включено уменьшение движения, вместо видео используется статичный фон.

## Вопросы и решения

<details>
<summary><strong>Мод не запускается или тема не появилась</strong></summary>

Полностью закрой Яндекс Музыку, включая её значок в трее, затем снова запусти мод. Уже работающий экземпляр приложения может помешать подключению темы.

Скрипт ищет установленное приложение в стандартной папке:

```text
%LOCALAPPDATA%\Programs\YandexMusic
```

Если приложение установлено в другом месте, для ручного запуска потребуется изменить путь в `src/launch.cjs`.

</details>

<details>
<summary><strong>Почему нет текста песни?</strong></summary>

Строки появляются только у треков, для которых Яндекс Музыка предоставляет синхронный текст. Если его нет, область текста остаётся пустой.

</details>

<details>
<summary><strong>Как запустить из исходников?</strong></summary>

Для ручного запуска нужен **Node.js 22 или новее**, доступный через команду `node`, и установленная Яндекс Музыка.

1. Скачай репозиторий через **Code → Download ZIP** и распакуй архив либо клонируй его:

   ```bash
   git clone https://github.com/murroch/yandexmusic-mod.git
   ```

2. Полностью закрой Яндекс Музыку.
3. Запусти `src/Launch.cmd`.

Также можно выполнить из корня репозитория:

```bash
node src/launch.cjs
```

Отдельная установка npm-зависимостей не требуется: скрипт использует встроенные возможности Node.js.

</details>
